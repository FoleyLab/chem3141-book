# CHEM 3141: Quantum Mechanics

Welcome to the interactive companion for CHEM 3141: Quantum Mechanics. This Jupyter Book collects lecture notes, problem sets, computational sets, and reference material in one place so that you can read, calculate, visualize, and experiment as you learn.

# What Is a Jupyter Book?

A Jupyter Book is a website built from a mixture of text, equations, figures, and Jupyter notebooks. Some pages behave like normal textbook chapters. Other pages are notebooks, which means they contain Python code cells that you can run, edit, and extend.

When you are reading the book online, use the table of contents on the left to move between sections. Use the page contents on the right to jump within a page. If a page is a notebook, the launch menu near the top of the page lets you open an executable copy in another environment.

# What You'll Find Here

This book integrates several learning modes to help you build fluency with quantum mechanics.

## Lecture Notes

The lecture notes introduce the mathematical structure, model systems, and physical ideas used throughout the course. These pages are a good place to start when you want the conceptual path through a topic.

## Problem Sets

The problem sets give you practice with derivations, calculations, and interpretation. Use these to check whether the formalism is becoming something you can actually use.

## Computational Sets

The computational sets are Jupyter notebooks designed for hands-on exploration. They use Python to model quantum systems, visualize wavefunctions and spectra, and connect analytic formulas to numerical experiments.

Each computational set can be read directly in the book, but the real benefit comes from launching the notebook and running the cells yourself. You are encouraged to change parameters, rerun cells, and ask "what happens if..." as you work.

## Dynamic Visualizations

Many notebooks include plots, sliders, or interactive visualizations that help make abstract ideas more concrete, from particle-in-a-box states to spherical harmonics, vibrational spectra, and light-matter coupling.

# How to Launch a Notebook in Google Colab

1. Open a computational set from the table of contents.
2. Click the launch button near the top of the page. It looks like a rocket.
3. Choose **Colab** from the launch menu.
4. Sign in with a Google account if prompted.
5. In Colab, run cells with **Shift+Enter** or the play button beside each cell.
6. If Colab asks to install or import packages, run the setup cells near the top of the notebook first.

Colab opens a copy of the notebook. Changes you make there do not change the course website. If you want to keep your work, save a copy to your Google Drive from within Colab.

# How to Use This Book

Start with the lecture notes for the main ideas, then use the computational sets to test those ideas numerically. When a notebook includes editable code, try changing one thing at a time and rerunning nearby cells so you can connect the output to the change you made.

The goal is not only to read about quantum mechanics, but to build enough familiarity that equations, plots, and code begin to reinforce one another.
